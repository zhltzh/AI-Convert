常见问题

Markdown 表格转 Excel FAQ

解析和导出均在浏览器中进行。

支持多个 Markdown 表格吗？

支持。下载 Excel 时，每个表格会成为一个独立工作表；下载 CSV 或复制时使用第一个表格。

为什么没有识别到表格？

请确认表头下一行使用至少三个连字符，例如 | --- | --- |。

中文会乱码吗？

XLSX 会保留中文；CSV 文件包含 UTF-8 BOM，使用新版 Excel 或 WPS 打开可正常显示中文。

内容会上传吗？

不会。Markdown 内容只在当前浏览器中解析，文件也在本地生成。
