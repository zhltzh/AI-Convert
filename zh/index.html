常见问题

关于 Markdown 万能转换器

Markdown 和 MD 文件有什么区别？

Markdown 是一种轻量标记格式；MD 文件通常是以 .md 或 .markdown 为扩展名、保存 Markdown 内容的文件。本工具同时支持粘贴 Markdown 内容和上传 MD 文件。

AI 内容可以直接转换吗？

可以。DeepSeek、豆包、腾讯元宝、通义千问、文心一言、ChatGPT、Claude 等 AI 输出中常见的标题、列表、表格和引用结构，可作为 Markdown 内容粘贴后转换。

哪些办公文件可以转 Markdown？

支持 DOCX、Excel、CSV 和包含可选文字的 PDF。旧版 .doc 请先在 Word 或 WPS 中另存为 .docx；扫描 PDF 需要 OCR，当前会明确提示无法直接提取文字。

PDF 中的图片会怎样处理？

当前会提取可选文字；含图片或图形的页面会保留可提取的文字并提示你检查结果。扫描件或纯图片 PDF 不会被误报为已成功转换。

我的文件会上传到服务器吗？

不会。当前转换过程在你的浏览器本地完成；请仍避免在任何在线工具中处理不应暴露的敏感资料。
