文心一言怎么转 Word？

文心一言（ERNIE Bot）是百度的大模型，回答同样是 Markdown 格式。复制后粘贴到转换工具就能导出 docx，标题层级和表格都能保留。整个过程在浏览器本地完成，提问内容不会上传。

四步完成转换

  1. 复制回答：在文心一言对话里找到要导出的回答，点下方的复制按钮。用鼠标拖选再复制会丢掉 Markdown 符号。
  2. 打开工具：进入 Markdown 转 Word 页面。
  3. 粘贴并检查：粘到左侧输入框，右侧会即时预览。重点看标题层级对不对、表格是不是真表格。
  4. 导出：点「生成 Word」，浏览器本地生成 docx 并下载。
文心一言的「插件调用」结果（比如调用搜索、文档解析）有时候格式比较杂，粘贴后建议先扫一眼预览再导出。

复制时的三个细节

  • 用复制按钮，别拖选：拖选拿到的是渲染后的富文本，## 符号已经没了，粘到 Word 里就成一堆没有层级的段落。
  • 长回答分段：超过几千字的回答建议分两三次粘贴，每次粘完看一眼预览，比一次贴进去更容易定位格式问题。
  • 删掉客套话：「希望以上内容对你有帮助」这类收尾，导出前直接删，文档会干净很多。

需要提前知道的限制

  • LaTeX 公式（$...$）保留为纯文本，不会渲染成 Word 公式。
  • 代码块保留缩进换行，不带语法高亮。
  • 文心一言生成的配图不在 Markdown 里，需要单独保存后在 Word 中插入。
  • 表格里的合并单元格会被拆开，需要在 Word 里手动合并。

常见问题

文心一言的回答可以转 Word 吗？

可以。复制文心一言的 Markdown 内容粘贴到转换工具，即可在浏览器本地生成 docx。

需要登录或付费吗？

不需要。免费使用，无需注册登录。

转换会把提问内容上传吗？

不会。转换在浏览器本地完成，内容不经过任何服务器。

文心一言 4.0 的回答也能转吗？

可以，所有版本的文本回答都能转换。
