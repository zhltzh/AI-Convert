AI 内容怎么转 Markdown？

很多时候需求是反过来的：不是把 Markdown 转成文档，而是把 Word、Excel、网页里的内容整理成 Markdown，好存进笔记软件或者继续让 AI 加工。这篇讲清楚哪些格式能转、怎么转、转完要注意什么。

为什么要把内容转成 Markdown

三个实际场景：

  • 存进笔记软件：Obsidian、Logseq 这类工具用 Markdown 作为原生格式，Word 粘进去会变成一大坨纯文本。
  • 继续喂给 AI：把 Excel 表格转成 Markdown 表格，粘给 AI 分析，比截图或者文字描述准确得多。
  • 发布到博客或 GitHub：Markdown 是静态站点和 README 的通用格式，改起来比 HTML 舒服。

哪些格式可以转

源格式支持情况说明
Excel（.xlsx）/ CSV支持转成 Markdown 表格，多工作表分别处理
Word（.docx）支持标题、列表和表格转成对应 Markdown 语法，复杂排版会简化
文本型 PDF支持能提取文字的 PDF 可以转；扫描件（图片）不行，需要先 OCR
网页内容手动复制后在工具里粘贴，或先用浏览器插件转成 Markdown

操作步骤

  1. 打开 办公文件转 Markdown 工具。
  2. 点击上传区域选择文件，或直接拖文件进来。支持一次选多个。
  3. 等待浏览器本地解析（文件不上传，解析在你的电脑上完成）。
  4. 在预览区检查生成的 Markdown，确认表格结构、标题层级正确。
  5. 点「复制 Markdown」把结果复制到剪贴板，粘到你需要的编辑器里。
扫描版 PDF（整页是图片）提取不出文字。遇到这种文件，先用 文档扫描 做 OCR，拿到文字后再转 Markdown。

转换后要检查什么

  • 表格列数：源文件里有合并单元格的，转出来列会错位，需要手动调整。
  • 标题层级：Word 里用「加粗」冒充标题的，转出来是普通段落，要手动加 #。
  • 列表嵌套：多级列表的缩进可能丢失，检查一下第二级是不是还缩进着。
  • 图片：图片不会转成 Markdown（Markdown 里图片是链接），需要单独上传图床再手动插入。

常见问题

Excel 能直接转成 Markdown 表格吗？

可以。上传 xlsx 或 csv，工具会转成标准 Markdown 表格语法，多个工作表分别生成。

扫描版 PDF 能转吗？

不能直接转，因为扫描件是图片没有文字层。需要先做 OCR 识别文字，再转 Markdown。

转换需要上传文件吗？

不需要。解析和转换在浏览器本地完成，文件不上传服务器。

转换后的 Markdown 能直接放进 Obsidian 吗？

可以。复制生成的 Markdown 文本，粘贴到 Obsidian 的笔记里即可。
