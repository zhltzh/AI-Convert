表格转换教程

Excel 和 CSV 表格怎么转成 Markdown？

把 Excel 数据放进 README、Notion、Obsidian、知识库或 AI 提示词时，Markdown 表格通常比截图更容易编辑和复用。本教程介绍安全、快速的本地转换方法。

更新于 2026 年 7 月 26 日 · 约 5 分钟

最快的方法

  1. 打开 Aixuno 的 Excel / CSV 转 Markdown 工具；
  2. 选择一个 .xlsx、.xls 或 .csv 文件；
  3. 多工作表文件选择需要的 Sheet；
  4. 复制 Markdown，或下载为 .md 文件。
文件在浏览器本地读取，不会上传到 Aixuno 的应用服务器。重要或敏感表格仍应确认设备和浏览器环境可信。

转换前怎样整理表格

  • 第一行使用简短、唯一的列名；
  • 删除仅用于视觉排版的空行和空列；
  • 尽量避免合并单元格，因为 Markdown 表格不支持合并；
  • 将公式结果确认无误后再转换；
  • 过宽的表格可拆成两个主题明确的小表。

为什么竖线会被转义

Markdown 使用竖线 | 分隔单元格。单元格内容本身包含竖线时，转换器会添加反斜杠，避免表格结构被破坏。这是标准处理，不需要手动删除。

CSV 中文乱码怎么办

优先从 Excel 或 WPS 导出 UTF-8 编码的 CSV。如果源文件仍然乱码，可重新“另存为 CSV UTF-8（逗号分隔）”，再上传转换。转换完成后也可直接下载 UTF-8 编码的 Markdown 文件。

转换后可以用在哪里

生成的表格适合放入 GitHub README、技术文档、Notion、Obsidian、语雀，以及提交给 AI 进行汇总、分类或数据解释。对于数百行以上的大表格，建议先筛选必要行列，避免文档难以阅读。

表格里有多个工作表会怎样

一次只转换一个工作表。上传后如果工作簿包含多个表，会出现工作表选择器，默认渲染第一张。切换工作表后重新转换，才能把其余的表也取出来。

电子表格有三件事 Markdown 表达不了

  • 合并单元格。合并区域的内容只保留在左上角单元格，被覆盖的单元格是空的，所以合并表头常常需要手动补一遍。
  • 单元格样式。底色、边框、数字格式都属于视觉表现，Markdown 表格一个都不带。
  • 公式。只传递计算结果，公式本身不会被带过去。

哪些输入能用，哪些不能

输入是否支持说明
.xlsx、.xls、.csv支持转换成竖线表格
.docx支持段落和表格转成 Markdown
带文本层的 PDF支持需要 PDF 里有可选中的文字
扫描版或纯图片 PDF不支持需要先做 OCR 再转换
旧版 .doc不支持先在 Word 或 WPS 里另存为 .docx

关于表格转换的问题

能一次转换所有工作表吗？

不能，一次只转一张。切换工作表选择器后再转一次。

为什么合并的表头缺了内容？

合并区域只有左上角单元格存值，被覆盖的单元格是空的，表头需要手动补一遍。

扫描版 PDF 能转吗？

不能直接转。扫描件没有文本层，需要先做 OCR。
