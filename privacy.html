Privacy

Your content stays in your browser by default.

Aixuno's core conversion tools are designed to process content locally in your browser. We do not operate an account system or upload the text you paste or the spreadsheet files you select to an Aixuno application server.

Content processed locally

  • Text pasted into Markdown editors;
  • Excel and CSV files you select and their tabular contents;
  • Generated Word, PDF, Markdown, and rich-text results.

Third-party resources

Some parsing and export features load browser scripts from public CDNs when required. A CDN may process standard network request information under its own policy, but your conversion content is not sent as a request parameter to that CDN.

Future analytics

If anonymous usage analytics are added, they will be limited to aggregated feature events such as tool opened, export succeeded, or export failed. Pasted text, file contents, and file names will not be recorded. This page will be updated before analytics are introduced.

Changes

This notice will be updated when material changes are made to product capabilities or data practices.
