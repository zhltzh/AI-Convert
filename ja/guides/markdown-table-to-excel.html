Markdown の表を Excel に移す方法

更新：2026 年 8 月 9 日

AI アシスタントは比較データを Markdown の表で返すことが多いもの。縦棒、整列行、複数行セルがデータの一部にならないよう、正しく変換・コピーしましょう。

最短の手順

  1. 表にヘッダー行と区切り行が 1 行ずつあることを確認します。
  2. Markdown を HTML でプレビューして、列の境目を確認します。
  3. 表示された表を Excel にコピーしたら、日付と数値を必ず確認します。

よくある問題

  • セル内の縦棒（|）が、そのまま余分な列を作ってしまう。
  • セル内の改行が、スプレッドシート上の余分な行になる。
  • Excel が値を数値と見なすと、先頭のゼロが消える。

逆方向の変換が必要なときは

Excel や CSV のファイルから Markdown の表が必要な場合は、Aixuno の「Office ファイルから Markdown」をお使いください。シートを選んで、生成される表をプレビューできます。

複数の表は複数のシートに

Markdown の中で見つかった表は、それぞれ独立したワークシートになり、出現順に番号が付きます。つまり元のテキストに表が 2 つあれば、シートも 2 枚——1 枚に連結されるわけではありません。

整列行が決めること

ヘッダーの下のハイフン行が列の整列を決め、そのままスプレッドシートに引き継がれます：

Markdown意味Excel での結果
:---左寄せ文字列が左端から始まる
:---:中央寄せセル内で中央に表示
---:右寄せ数値列に便利

知っておくべき制限

  • 行またぎ・列またぎの結合には Markdown の記法がないため、結合ヘッダーは Excel 側で組み直す必要があります。
  • エスケープした縦棒 \| は 1 つのセルに収まりますが、エスケープしていない縦棒はセルを 2 つに割ります。
  • 数値は、Excel が開くときに変換しないかぎり文字列として届きます。数式を使う前に列の型を確認してください。

Excel 出力についての疑問

複数の表はどう扱われますか？

各表は、元のテキストでの出現順に独立したワークシートになります。

結合セルは保持されますか？

いいえ。Markdown には行またぎ・列またぎの記法がないため、結合は Excel で組み直す必要があります。

数値は数値のまま入りますか？

値はセルの内容として書き込まれます。文字列として入った数値は計算されないため、数式の前に列の型を確認してください。

シートの表示がおかしいとき

  • 全部が 1 列に入った。ヘッダーの下にハイフンの区切り行がなく、表として認識されていません。
  • 行が抜けている。表の中の空行は表を終わらせます。行の間の空行を削除してください。
  • 数値が文字列扱い。対象の列を選択して、数値形式に変換してから数式をお使いください。
