Markdown の表を Excel / CSV に変換

ChatGPT や Claude などの AI が生成した Markdown の表を、編集可能な Excel / CSV ファイルに変換します。登録不要で、処理はすべてブラウザの中で完結します。

サンプル表を読み込み中…
Markdown の表複数の表を含められます
表のプレビュー各表が独立したワークシートになります

使い方

AI の表から、そのまま使えるシートへ

01

Markdown の表を貼り付け

AI の回答、MD ファイル、エディタからコピーした標準的な Markdown の表に対応します。

02

プレビューで確認

複数の表を自動認識し、日本語・数値・空セル・改行もそのまま保持します。

03

Excel または CSV に書き出し

複数の表は XLSX の別々のワークシートに。CSV は最初の表を書き出します。

詳しい使い方

Markdown の表を Excel にする完全ガイド

ステップ 1：Markdown の表を用意する

AI の回答から表を含む Markdown をコピーするか、.md ファイルから表部分を取り出します。列は縦棒（|）で区切り、ヘッダーとデータ行の間にハイフンの区切り行を入れます。

ステップ 2：貼り付けて認識させる

入力欄に貼り付けると、Markdown の表がすべて自動認識されます。複数の表がある場合は、プレビュー領域にそれぞれ分けて表示されます。

各表の列数が揃っているか、ヘッダーが正しく認識されているかを確認してください。認識されない場合は、ヘッダーの下の区切り行が |---| の形式になっているか確認します。

ステップ 3：Excel に書き出す

「Excel をダウンロード」ボタンを押すと、.xlsx ファイルが生成されます。複数の表がある場合は、それぞれ別のワークシート（シート）に配置されます。

書き出されたファイルはヘッダーとデータを保持しているので、Excel でそのまま編集・フィルター・並べ替え・グラフ作成に使えます。

よくある質問

表変換ツールのよくある質問

解析と書き出しは、すべてブラウザの中で行われます。

複数の Markdown の表に対応していますか？

はい。Excel ダウンロード時は各表が独立したワークシートになり、CSV ダウンロードとコピーは最初の表が対象になります。

表が認識されないのですが？

ヘッダー行の下に | --- | --- | のような区切り行（3 文字以上のハイフン）があるか確認してください。

日本語は文字化けしませんか？

XLSX は日本語をそのまま保持します。CSV は UTF-8 BOM 付きで書き出すため、Excel で開いても文字化けしません。

入力した内容はアップロードされますか？

いいえ。解析もファイル生成も、すべてブラウザの中だけで行われます。

セル内の縦棒と改行はどう扱われますか？

セル内の縦棒はバックスラッシュでエスケープしてください。HTML の <br> は書き出し時にセル内の改行に変換されます。

表と Markdown の処理を続ける

活用場面

Excel に戻したいとき

01

表で計算をしたい

Markdown の表は読むだけ。xlsx に書き出せば、数式やピボットテーブルが使えます。

02

Markdown を使わない相手に渡す

開いた瞬間に編集できるので、書式の説明は不要です。

03

絞り込みと並べ替えが必要

Excel のフィルターは、テキストを手で探すよりはるかに速いです。

制限

このツールでできないこと

01

結合セルの再現

Markdown には行またぎ・列またぎの書式がないため、結合は Excel 側で行ってください。

02

列の型の自動判定

数値はセルの内容どおりに書き込まれます。数式を使う前に列の書式を確認してください。

03

セルのスタイル保持

色・罫線・表示形式は、Markdown の表現範囲外です。
