Frequently asked questions

Office files to Markdown FAQ

Supported formats, limitations, and local processing.

Which files can I convert?

The converter supports Excel (XLSX, XLS), CSV, DOCX, and PDFs that contain selectable text.

Can it convert a scanned PDF?

Not yet. A scanned or image-only PDF needs OCR before its text can be converted to Markdown.

Can it read an old DOC file?

Save the file as DOCX in Word, LibreOffice, or WPS first, then upload the DOCX version.

Are files uploaded?

No. Supported files are read and converted in your browser.

Will complex formatting be identical?

No. Markdown represents content structure rather than page layout, so text boxes, images, and complex tables may require review.

Limits

What this tool will not do

01

Keep merged cells intact

A merged range stores its value in the top-left cell only, so merged headers must be rebuilt.

02

Convert every sheet at once

One sheet is converted per run; switch the selector and convert again for the others.

03

Read a scanned PDF

A scanned file has no text layer and needs OCR before it can be converted.
