Frequently asked questions

Markdown to PDF FAQ

What to expect before exporting a PDF.

Can I convert an MD file to PDF?

Yes. Upload a .md or .markdown file, check the preview, and download the generated PDF.

Can I use AI-generated Markdown?

Yes. Paste structured output from ChatGPT, Claude, Gemini, Copilot, Perplexity, or another assistant.

Are tables and code blocks supported?

Common Markdown tables, quotes, lists, headings, and code blocks are included in the rendered document.

Is the file uploaded?

No. The supported preview and PDF export run locally in your browser.

Should I review the PDF?

Yes. Check pagination, links, fonts, and complex tables before printing or publishing an important document.

When to use it

Where a PDF is the right output

01

Sending to someone who only reads

A recipient who opens the file to read it, not to edit it, cannot accidentally change the layout.

02

Printing or archiving

Fixed A4 pages print predictably and keep the same pagination months later.

03

Locking a finished version

When a draft is approved, a PDF makes the approved state explicit.

Limits

What this tool will not do

01

Change page size or orientation

The current version exports A4 portrait only; landscape and custom margins are not configurable.

02

Carry images across

Images are not part of copied text, so they do not appear in the generated PDF.

03

Keep very wide tables readable

About 186 mm of content width is available, so tables with many columns get compressed.
