Preguntas frecuentes

Sobre el conversor Markdown

¿Qué diferencia hay entre Markdown y un archivo MD?

Markdown es un formato de marcado ligero. Un archivo MD guarda contenido Markdown con extensión .md o .markdown.

¿Puedo convertir directamente contenido generado por IA?

Sí. Pega contenido de ChatGPT, Claude, Gemini, Copilot, Perplexity, Grok u otro asistente.

¿Qué archivos de Office se pueden convertir?

Se admiten DOCX, Excel, CSV y PDF con texto seleccionable. Los PDF escaneados necesitan OCR.

¿Qué ocurre con las imágenes de un PDF?

Se extrae el texto seleccionable y se recomienda revisar las páginas con imágenes o gráficos.

¿Se suben mis archivos?

No. La conversión se ejecuta localmente en tu navegador.
