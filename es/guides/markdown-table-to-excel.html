Cómo llevar una tabla Markdown a Excel

Actualizado el 9 de agosto de 2026

Los asistentes de IA suelen devolver datos comparativos en tablas Markdown. Conviértelas o cópialas con cuidado, para que barras, filas de alineación y celdas multilínea no acaben formando parte de los datos.

Método rápido

  1. Confirma que la tabla tiene una fila de encabezado y una fila separadora.
  2. Previsualiza el Markdown como HTML para comprobar los límites de las columnas.
  3. Copia la tabla renderizada a Excel y verifica fechas y números.

Problemas frecuentes

  • Una barra vertical literal dentro de una celda puede crear una columna de más.
  • Un salto de línea dentro de una celda puede generar filas extra en la hoja.
  • Los ceros a la izquierda pueden desaparecer cuando Excel trata los valores como números.

¿Y la conversión inversa?

Si ya tienes un archivo Excel o CSV y necesitas una tabla Markdown, usa Aixuno Excel a Markdown. Permite elegir una hoja y previsualizar la tabla generada.

Cuántas tablas, cuántas hojas

Cada tabla encontrada en el Markdown se convierte en su propia hoja, numerada por orden de aparición. Dos tablas en la fuente llegan como dos hojas, no como una hoja apilada.

Qué controla la fila de alineación

La línea de guiones bajo el encabezado decide la alineación de las columnas, y se traslada a la hoja de cálculo:

MarkdownSignificadoResultado en Excel
:---Alineado a la izquierdaEl texto empieza en el borde izquierdo
:---:CentradoContenido centrado en la celda
---:Alineado a la derechaÚtil para columnas numéricas

Límites que conviene conocer

  • Markdown no tiene sintaxis para celdas combinadas: los encabezados fusionados hay que reconstruirlos en Excel.
  • Una barra escapada \| se queda en una celda; una barra sin escapar divide la celda en dos.
  • Los números llegan como texto salvo que Excel los convierta al abrir: comprueba el tipo de columna antes de escribir fórmulas.

Preguntas sobre el archivo Excel resultante

¿Cómo se gestionan varias tablas?

Cada tabla se convierte en su propia hoja, numerada por orden de aparición en la fuente.

¿Se pueden conservar las celdas combinadas?

No. Markdown no tiene sintaxis de combinación de filas o columnas: las combinaciones hay que rehacerlas en Excel.

¿Los números siguen siendo numéricos?

Los valores se escriben como contenido de celda. Comprueba el tipo de columna antes de escribir fórmulas: los números en formato texto no calculan.

Si la hoja se ve mal

  • Todo llegó en una sola columna.La tabla no tiene fila separadora de guiones bajo el encabezado: no se reconoció como tabla.
  • Faltan filas.Una línea vacía dentro de una tabla la termina; quita las líneas vacías entre filas.
  • Los números se comportan como texto.Selecciona la columna y conviértela a formato numérico antes de usar fórmulas.

Herramientas relacionadas

  • Archivos de Office a Markdown — el camino inverso.
  • Markdown a PDF — cuando la tabla debe leerse, no calcularse.
