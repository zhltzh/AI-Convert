How to use these guides

Each guide follows the same shape: the situation it applies to, the steps, the limits you should know before relying on the output, and a comparison with alternative routes. The limits section is the part worth reading first when something goes wrong.

  • Start with the guide that matches the platform you copied from.
  • Every guide links to the tool that performs the conversion.
  • Where a guide names a limitation, it is a property of the format, not a temporary bug.

What is covered

The guides cover exporting AI answers to Word, PDF and HTML, moving spreadsheets and documents into Markdown, and turning Markdown tables back into spreadsheets. Chinese-language editions add WeChat article formatting and local file workflows.
