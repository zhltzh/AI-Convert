How to Move a Markdown Table into Excel

Updated August 9, 2026

AI assistants often return comparison data as a Markdown table. Convert or copy it carefully so pipes, alignment rows and multiline cells do not become part of the data.

Quick method

  1. Confirm that the table has one header row and a separator row.
  2. Preview the Markdown as HTML to check column boundaries.
  3. Copy the rendered table into Excel, then verify dates and numbers.

Common problems

  • A literal pipe inside a cell can create an extra column.
  • Line breaks inside a cell may create extra spreadsheet rows.
  • Leading zeros can disappear when Excel treats values as numbers.

How many tables become how many sheets

Every table found in the Markdown becomes its own worksheet, numbered in the order it appears. Two tables in the source therefore arrive as two sheets, not one stacked sheet.

What the alignment row controls

The line of dashes under the header decides column alignment, and it carries through to the spreadsheet:

MarkdownMeaningResult in Excel
:---Left alignedText starts at the left edge
:---:CentredContent centred in the cell
---:Right alignedUseful for numeric columns

Limits worth knowing

  • Row spans and column spans have no Markdown syntax, so merged headers must be rebuilt in Excel.
  • An escaped pipe \| stays inside one cell; an unescaped pipe splits the cell in two.
  • Numbers arrive as text unless Excel converts them on open — check the column type before running formulas.

Questions about the Excel output

How are multiple tables handled?

Each table becomes its own worksheet, numbered in the order it appears in the source.

Can merged cells be preserved?

No. Markdown has no row or column span syntax, so merges must be rebuilt in Excel.

Do numbers stay numeric?

Values are written as cell content. Check the column type before running formulas, since text-formatted numbers will not calculate.

If the spreadsheet looks wrong

  • Everything landed in one column. The table has no delimiter row of dashes under the header, so it was not recognised as a table at all.
  • Rows are missing. A blank line inside a table ends it; remove empty lines between rows.
  • Numbers behave as text. Select the column and convert it to a number format before using formulas.
