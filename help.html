Help and quick reference

What each tool takes, what it produces, and what to check when the output does not look right.

Start here

  1. Copy what you want to convert — an AI answer, the contents of a Markdown file, or a spreadsheet.
  2. Paste it into the matching tool. The preview updates as you type or as the file is read.
  3. Check the preview, then export the file or copy the result.

Common questions

Do I need an account?

No. No tool requires registration, and there is no account system to create.

Are my files uploaded?

No. Text and files are read and converted inside the browser. Nothing is sent to an Aixuno server.

Which Markdown features are supported?

Headings, paragraphs, lists, links, tables, blockquotes and fenced code blocks. Footnotes and raw HTML are kept as text rather than interpreted.

Can it convert a scanned PDF?

Not yet. A scanned file has no text layer, so it needs OCR before it can be converted.

Why did my headings disappear after pasting?

Either the copy came from a rich-text source that dropped the markers, or the hashes were written without a space after them. Both are fixed by re-adding the markers on their own lines.

Can I change the PDF page size?

No. The current version exports A4 portrait only, with 12 mm side margins and a page counter in the bottom-right corner.

Is there a length limit?

No fixed limit is applied. Very long documents are bounded only by what the browser can hold in a text field, so splitting into two or three parts is more reliable.

Will this work on a phone?

Yes, the tools run in mobile browsers. Editing long tables is still easier on a desktop screen.

Data and privacy

Pasted text and selected files stay in the browser's memory. Page analytics record which page was viewed, not what was converted. The privacy notice describes the full data flow, including the third-party scripts used for parsing.
