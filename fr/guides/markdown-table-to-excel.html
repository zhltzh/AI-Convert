Déplacer un tableau Markdown vers Excel

Mis à jour le 9 août 2026

Les assistants IA renvoient souvent des données comparatives en tableau Markdown. Convertissez-les ou copiez-les avec soin, pour que tubes, lignes d’alignement et cellules multilignes ne deviennent pas partie des données.

Méthode rapide

  1. Confirmez que le tableau compte une ligne d’en-tête et une ligne de séparation.
  2. Prévisualisez le Markdown en HTML pour vérifier les limites des colonnes.
  3. Copiez le tableau rendu dans Excel, puis vérifiez dates et nombres.

Problèmes fréquents

  • Un tube littéral dans une cellule peut créer une colonne en trop.
  • Un saut de ligne dans une cellule peut créer des lignes de feuille en trop.
  • Les zéros de tête peuvent disparaître quand Excel traite les valeurs comme des nombres.

La conversion inverse ?

Si vous avez déjà un fichier Excel ou CSV et qu’il vous faut un tableau Markdown, utilisez Aixuno Excel vers Markdown. Il permet de choisir une feuille et de prévisualiser le tableau généré.

Combien de tableaux, combien de feuilles

Chaque tableau trouvé dans le Markdown devient sa propre feuille, numérotée dans l’ordre d’apparition. Deux tableaux dans la source arrivent donc en deux feuilles, pas en une feuille empilée.

Ce que contrôle la ligne d’alignement

La ligne de tirets sous l’en-tête décide de l’alignement des colonnes, et cela se reporte dans la feuille de calcul :

MarkdownSignificationRésultat dans Excel
:---Aligné à gaucheLe texte commence au bord gauche
:---:CentréContenu centré dans la cellule
---:Aligné à droiteUtile pour les colonnes numériques

Limites à connaître

  • Fusions de lignes et de colonnes n’ont pas de syntaxe Markdown : les en-têtes fusionnés doivent être reconstruits dans Excel.
  • Un tube échappé \| reste dans la même cellule ; un tube non échappé coupe la cellule en deux.
  • Les nombres arrivent en texte, sauf si Excel les convertit à l’ouverture : vérifiez le type de colonne avant d’écrire des formules.

Questions sur le fichier Excel obtenu

Comment les tableaux multiples sont-ils gérés ?

Chaque tableau devient sa propre feuille, numérotée dans l’ordre d’apparition dans la source.

Les cellules fusionnées sont-elles conservées ?

Non. Markdown n’a pas de syntaxe de fusion de lignes ou de colonnes : les fusions doivent être refaites dans Excel.

Les nombres restent-ils numériques ?

Les valeurs sont écrites comme contenu de cellule. Vérifiez le type de colonne avant d’écrire des formules : des nombres au format texte ne calculent pas.

Si la feuille semble fausse

  • Tout est arrivé dans une seule colonne.Le tableau n’a pas de ligne de séparation en tirets sous l’en-tête : il n’a pas été reconnu comme tableau.
  • Des lignes manquent.Une ligne vide à l’intérieur d’un tableau y met fin ; supprimez les lignes vides entre les rangées.
  • Les nombres se comportent en texte.Sélectionnez la colonne et convertissez-la en format numérique avant d’utiliser des formules.

Outils associés

  • Fichiers Office vers Markdown — dans l’autre sens.
  • Markdown vers PDF — quand le tableau doit être lu, pas calculé.
