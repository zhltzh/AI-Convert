# Aixuno 搜索引擎收录清单

正式站点：`https://aixuno.com/`

站点地图：`https://aixuno.com/sitemap.xml`

## 第一优先级

### 百度搜索资源平台

1. 添加 `https://aixuno.com`。
2. 优先使用 HTML 文件验证；将验证文件放在项目根目录后部署。
3. 在“资源提交 / 普通收录”中提交站点地图。
4. 使用 URL 提交功能提交首页、工具页和新发布的教程页。
5. 收录稳定后再申请站点 Logo、品牌展现等站点属性。

入口：<https://ziyuan.baidu.com/>

### Bing Webmaster Tools

1. 添加并验证 `https://aixuno.com`。
2. 提交站点地图。
3. 在 URL Inspection 中检查首页和主要工具页。
4. 查看 IndexNow 报告；本站每次成功部署后会自动提交 sitemap 中的 URL。

入口：<https://www.bing.com/webmasters/>

## 第二优先级

### 360 搜索

1. 先提交网站首页。
2. 注册站长平台后验证网站并提交站点地图。

入口：<https://info.so.360.cn/site_submit.html>

### Google Search Console

1. 添加域名资源 `aixuno.com`，推荐使用 DNS TXT 验证。
2. 提交站点地图。
3. 检查中文与英文首页的索引状态。

入口：<https://search.google.com/search-console/>

## 发布后的固定动作

- 新增、更新或删除可索引页面时同步更新 `sitemap.xml`。
- 确认每个页面都有唯一的标题、描述和 canonical。
- 新教程从首页或相关工具页获得至少一个站内链接。
- 每月检查抓取错误、未收录原因、搜索词与点击率。
- 不购买批量外链，不批量生成低质量关键词页面。
